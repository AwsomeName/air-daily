# 丙午流光研发日记

丙午流光（Bingwu Light）最初是为自己做一座个人墓碑、探索赛博永生：记录自己的形象、音容、记忆与对话逻辑，未来用墓碑上的手机代替照片，让来访者仍能与留下的自己对话，并希望借助太阳能一直“活”下去。项目从 iOS 起步，目前聚焦头部采集、静态重建与表情验证；完整对话与太阳能墓碑装置仍是愿景。
