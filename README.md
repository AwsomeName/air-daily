# AIR 项目研发日记

独立归档仓库：[AwsomeName/air-daily](https://github.com/AwsomeName/air-daily)。仓库根目录对应 AIR 项目的“研发日记”目录，素材随日记保存；工程证据链接指向主项目的固定提交，访问权限取决于主项目仓库。

用于整理「领航员-小眸」的研发过程，以及小红书、朋友圈等平台的发布草稿。每天使用一个 `YYYY-MM-DD` 子文件夹，日期按北京时间计算；跨日记录在正文注明起止时间。

## 每日目录

```text
研发日记/
  README.md
  日记模板.md
  2026-09-10/
    研发记录.md
    发布文案.md
    素材/
      README.md
```

- `研发记录.md`：当天实际进展、已验证结果、未完成事项和证据来源，便于后续复盘。
- `发布文案.md`：标题候选、小红书正文、短版文案、配图顺序及发布记录。
- `素材/`：当天选用的截图、封面和视频。文件名建议使用 `01-封面`、`02-功能演示` 等顺序前缀。

新一天复制模板中的两部分，分别保存为当天的研发记录和发布文案。一天内继续修改同一个日期目录；实际发布后，将平台、时间和链接补入发布记录。

写作以当天证据为准，区分已实现、已实测和待验证。公开文案优先讲用户能感受到的变化、具体遇到的问题及下一步；效果图标注为效果图，测试图不冒充真实使用。这里只保存草稿和素材，不代表已发布，也不自动创建每天的日记。
